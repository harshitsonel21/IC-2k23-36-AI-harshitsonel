# Lab 2: Heuristic Search Algorithms

## Aim / Problem Statement
Implement BFS, DFS, Greedy Best First Search, and A* on a graph and compare their paths and execution times.

## Algorithm
BFS uses a FIFO queue; DFS uses a stack; Greedy Best First expands the node with minimum heuristic h(n); A* expands the node with minimum f(n)=g(n)+h(n).

## How to run
```bash
python Lab2/search_algorithms.py
```
