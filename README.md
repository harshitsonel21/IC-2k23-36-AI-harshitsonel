# Lab 1: AI Environment, Production Systems and Water Jug Problem

## Aim / Problem Statement
Set up a Python-based AI environment, demonstrate a production-rule system, and solve the Water Jug Problem as a state-space search task.

## Algorithm
Represent each state as `(amount_in_A, amount_in_B)`. Apply legal fill, empty, and pour operators. Use BFS with a visited set until either jug contains the target amount.

## How to run
```bash
python Lab1/water_jug.py  # or python Lab1/production_rules.py
```
