# Lab 4: Knowledge Representation and Logical Reasoning

## Aim / Problem Statement
Represent simple knowledge as semantic triples and derive additional facts using rule-based inference.

## Algorithm
Store facts as `(subject, relation, object)` triples. Match each rule premise against the knowledge base and add its conclusion for the selected subject.

## How to run
```bash
python Lab4/knowledge_representation.py
```
